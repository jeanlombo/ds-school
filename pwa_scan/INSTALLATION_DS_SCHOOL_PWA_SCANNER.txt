DS SCHOOL PWA SCANNER V1 — INSTALLATION
=======================================

TYPE DE MISE À JOUR
-------------------
Mise à jour PARTIELLE. Ne supprimez pas le projet DS School existant.
Copiez le contenu du ZIP à la racine de :
C:\xampp\htdocs\ds-school
Puis acceptez le remplacement des deux fichiers existants :
- app\layout.tsx
- app\dashboard\safe-campus\page.tsx

-----------------
- app\mobile\scanner\page.tsx
- app\mobile\scanner\scanner.module.css

FONCTIONNEMENT
--------------
1. L'utilisateur se connecte normalement à DS School.
2. Il ouvre : https://ds-school.digigroupe.dev/mobile/scanner
3. Il autorise la caméra.
4. Il scanne un QR Code contenant l'UID d'une carte déjà enregistrée dans cartes_rfid.
5. Le passage est synchronisé immédiatement dans passages_rfid.
6. Sans Internet, le scan est stocké dans IndexedDB.
7. Au retour de la connexion, la synchronisation reprend automatiquement.

COMPATIBILITÉ
-------------
- QR caméra : navigateurs proposant BarcodeDetector (Chrome/Edge récents principalement).
- NFC Web : disponible seulement sur les appareils/navigateurs compatibles.
- Tous appareils : saisie manuelle et lecteurs USB HID fonctionnent.
- iPhone : l'installation PWA se fait via Safari > Partager > Sur l'écran d'accueil.

SÉCURITÉ
--------
- Aucun secret API n'est exposé dans la PWA.
- La route mobile utilise la session DS School et la permission SAFE_CAMPUS_VOIR.
- Les utilisateurs non connectés ne peuvent pas enregistrer de passage.
